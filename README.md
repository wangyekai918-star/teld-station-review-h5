## UI 与交互重点

| 区域 | 开发参考 |
| --- | --- |
| 初始状态 | 五个表情全部亮色，但没有默认选中值；标签隐藏。 |
| 表情选择 | 仅当前表情亮色，其他表情及文字变灰；选中图标放大回弹。 |
| 评价标签 | 根据满意度切换对应标签，两列排列。默认未选，可多选，再次点击取消；切换满意度清空标签选择，保留文字和照片。标签不填入文本框。 |
| 体验输入 | 选填，最多 200 字；200 字内不显示计数，201 字起显示并标红，超限不能提交。输入框固定 90px、5 行，超出内容在框内滚动。 |
| 添加照片 | 选填，最多 9 张，按顺序在单行内排列，可横向滑动。添加入口始终位于末尾，满 9 张隐藏，删除后恢复。 |
| 提交校验 | 点击“提交评价”时，只有表情必填。未选择时提示“请先选择你的评价”；可只选表情提交。 |
| 评价须知 | 只保留入口，链接由前端配置现有页面。 |

## 表情与标签对应规则

标签按下表顺序，从左到右、从上到下排列。每组默认都未选中，可多选，再次点击取消。

| 满意度 | 标签数量 | 对应标签（按显示顺序） |
| --- | --- | --- |
| 很不满意 | 5 个 | 经常跳枪、设备故障、无法充满、停车/进出不便、位置错误/难找 |
| 不满意 | 5 个 | 停车费与实际不符、有车占位、环境卫生差、指引不清晰、设备维护不及时 |
| 一般 | 3 个 | 充电慢、需要排队、收费规则不清晰 |
| 满意 | 6 个 | 设备维护及时、收费规则清晰、停车收费与实际相符、不用排队、导航准确、指引清晰好找 |
| 很满意 | 6 个 | 充电顺利、设备完好、充电快、现场管理好、环境卫生好、位置便利 |

页面中的“一般”对应原始标签表中的“一般满意”。切换满意度后展示对应的新标签组，并清空上一组的选择；文字和照片保留。

## 动画参数

| 动画 | 时长 | 效果 |
| --- | --- | --- |
| 表情及文字变色 | 200ms | 亮色与灰色平滑切换。 |
| 评价卡片伸缩 | 200ms | 标签行数变化时平滑改变高度，下方内容同步移动。 |
| 选中表情回弹 | 520ms | 缩放比例为 `1 → 1.28 → 0.94 → 1.06 → 1`；只缩放图标。 |

快速切换时从当前状态继续过渡，避免动画叠加。系统开启“减少动态效果”时跳过动画。
